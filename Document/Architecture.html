Architecture

Three layers, one rule: core never imports Tkinter. The GUI drives a background thread; the thread never touches a widget directly — it hands everything to the GUI through a queue.

How one run moves

Genuinely sequential — each stage depends on the one before it, and the progress bar is divided along these boundaries.

01Scan the masterCodes and tables cached once, page-parallel
02Crop the masterFigures extracted by ink clustering
03Per translationTOC · codes · counts · image match
04StylesheetEvery marked region, every language
05Text checksCollisions and untranslated English
06MetadataSize, pages, sheet, columns
07ReportOne workbook, nine sheets

Why that order: in a packaged build every worker process re-launches the exe. Without the freeze call first, each worker starts a second copy of the application instead of doing the work it was handed.

The logic behind each check

Each one exists because a simpler version of it was tried first and gave the wrong answer. The figure at the foot of each card is what it does on the Start 350 set — one master, eleven translations.

Table of contents

ProblemPage numbers move when text reflows, so comparing them finds differences that are not faults.

MechanismOnly the topic numerics are compared — 1, 1.1, 2.3.1. Those survive translation; titles and page numbers do not. The same insight powers page_mapper, which finds a topic's page in each language.

Library · MethodPyMuPDF's doc.get_toc(simple=True) for the outline tree, plus Python re to strip each title down to its leading numeric token before the two lists are diffed as sets.

11 / 11 PASS

Barcode & QR

ProblemA QR encodes a language-specific URL. Comparing the pixels can only ever fail.

MechanismCount and presence per page, not appearance. Decoded values are reported side by side so a reviewer sees the URLs differ by language — the expected outcome, not a finding.

Library · Methodpyzbar.pyzbar.decode() reads and decodes the symbol directly from a PyMuPDF page render; when pyzbar isn't available, an OpenCV fallback (cv2.findContours + connectedComponentsWithStats) detects the finder-pattern's blocky structure so presence is still counted even without a decode.

11 / 11 PASS

Figure extraction

ProblemMerging vector paths split one exploded diagram into 19 separate crops.

MechanismInk clustering: render the page, erase the text from the pixels, dilate by a small gap, and take connected components. A figure is whatever ink hangs together. Separator rules are stripped by a triad — isolation, thickness, span — so a solid pictogram and a barcode both survive while a rule does not.

Library · MethodPyMuPDF page.get_pixmap(dpi=) to rasterise, PyMuPDF's own text spans to blank out glyph pixels, then numpy thresholding (arr < threshold) plus cv2.dilate and cv2.connectedComponentsWithStats to cluster the remaining ink into figure boxes.

19 boxes → 1 · 92-page manual holds

Figure comparison

ProblemA page-1 logo matched page 59 at 29.5%. Normalised correlation against a blank template is numerically undefined and returns noise.

MechanismBlank crops are rejected before matching, a standard-deviation guard sits in the comparator, and nothing below 55% is credible. A coarse pass at 35% scale picks three candidate pages, then full resolution decides.

Library · MethodOpenCV cv2.matchTemplate with TM_CCOEFF_NORMED, run twice: a coarse pass at COARSE_SCALE=0.35 shortlists COARSE_KEEP=3 candidate pages by numpy standard deviation and correlation score, then full-resolution matchTemplate scores those candidates and MIN_CREDIBLE_MATCH=55.0 gates a real hit.

319 / 319 crops MATCH, zero CHECK

Image counts

ProblemCrop matching hunts master crops in the translation, so it is blind to a graphic only the translation has.

MechanismCount per topic on both sides and compare. Topic codes are the join, because page numbers are not stable across languages.

Library · MethodNo image library needed — figures are already boxed by the extraction step, so this is a plain Python dict/Counter tally per topic code, diffed symmetrically (master-has-more and translation-has-more are both reported) rather than by page position.

9 / 11 — both differences real

Stylesheet regions

ProblemOne question does not fit every region. A doc number, a QR and a heading each need a different test.

MechanismFive mutually exclusive modes, one per region, plus its own tolerances. A region nested inside a scope is searched across that whole scope rather than at fixed coordinates.

Library · MethodPyMuPDF page.get_text("dict", clip=) extracts the text and geometry per region; the "same pattern" mode derives a regex shape from the master text ([^\W\d_] for "a letter" across scripts, plus a digit-count gate) and searches it first in-place, then across the parent scope via Python re.

187 / 187 on the tuned stylesheet

Text overlap

ProblemBox intersection alone flagged the Greek page 20 — where the glyphs never touch. Accents make the box taller than the leading, so a box-only detector cries wolf on every Greek and Cyrillic page.

MechanismTier one intersects boxes. Tier two renders the overlap band at 300 dpi and measures the white between the ink — counting the blank rows at the band's edges was the bug that let a real collision through.

Library · MethodPyMuPDF get_text("dict") spans for a sweep-sorted box-intersection candidate pass, then PyMuPDF get_pixmap(dpi=300) to rasterise the overlap band and numpy row-sum ink profiling ((a<160).sum(axis=1) + np.flatnonzero for the longest interior zero-run) to confirm the glyphs actually touch.

0 false positives · catches an injected overrun

Untranslated text

ProblemEnglish function-word density alone gave 18 wrong hits — “for” is Danish, “in” is Italian, “of” is Dutch.

MechanismTwo tests. Verbatim — the line is word for word in the master — is the trustworthy one. Dense corroborates it, and catches English that is not in the master at all. Numeral-heavy lines are skipped, which removed the last false positive: a dimensions line, flagged because “in” is also an inch.

Library · MethodPyMuPDF get_text per line, Python unicodedata NFKC folding + re punctuation stripping to normalise, then set-membership against a master line inventory (verbatim) alongside an English function-word ratio over a fixed word list (dense), with a digit-share cutoff (MAX_DIGIT_SHARE=0.20) excluding numeral-heavy lines.

0 false positives · 1 / 1 planted miss

Hyperlinks & cross-references

ProblemTranslators break web URLs, lose anchor query parameters, or internal GoTo links point to wrong pages after text expansion.

MechanismExtracts URI and GoTo links via PyMuPDF page.get_links(), normalizes URLs (protocol, trailing slashes, case), and uses 2D spatial topic analysis (extract_topics_with_positions) to bind each link to its exact sub-topic on shared pages. SequenceMatcher aligns internal link targets.

Library · MethodPyMuPDF page.get_links(), Python difflib.SequenceMatcher, urllib.parse, in-memory stream directly to Excel sheet 10.

100% link coverage · zero false topic assignments

Margins & page overflow

ProblemText expansion in foreign languages (German, Finnish) spills outside column widths into print margins, getting sliced during industrial trimming.

MechanismAudits printable boundary envelopes across top, bottom, inner, and outer margins, accounting for alternating left/right page gutters. Flags any text block or image crop encroaching on forbidden trim zones.

Library · MethodPyMuPDF page.get_text("blocks") and figure geometry boundary tests against calibrated page trim tolerances.

Catches margin encroachments before physical print run

The five region modes

Exactly one per region. They answer different questions, and a region ticked for two would have to be scored twice with no rule for which score wins.

ModeThe question it answersUse it for
Exact matchIs the text identical?Addresses, contacts, trademarks
Scope only—A container that bounds its children and is never scored itself
Visual onlyDoes the picture match?Logos and artwork, ignoring any text
Present onlyIs it still there?QR codes and barcodes, whose contents differ by design
Same patternDoes it have the same shape?Doc numbers and language codes — six digits stay six digits

in place and moved matter for Same pattern: a shape found where it belongs passes; a generic shape found only elsewhere in the scope is reported for review, because with the language code deleted from all eleven translations, a scope-wide search for “two letters” still passed eight of them on ordinary words.
